# The Enterprise Digital Brain — Companion Repository

Public companion material for **The Enterprise Digital Brain**.

This repository intentionally contains a small set of runnable examples,
installation guidance, errata, and links to reader resources.

## Public samples

- `samples/router-agent/` — deterministic router-agent pattern
- `samples/evaluation/` — tiny evaluation harness

Reader-only code, labs, solutions, templates and release bundles are distributed
through the Companion Code Lab (PROJECT CODEVAULT).

## Resource IDs

Book examples use stable IDs such as `EDB-C07-PAT01`.
These IDs remain stable even when the implementation is updated.

## Security

Never commit credentials, tokens, private keys, customer data, or book-buyer
entitlement data to this repository.
